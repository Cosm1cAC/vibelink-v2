# 1.6.7：额度编辑、Bot 运行设置与开发网络

桌面「编辑额度」原来把表单插在十行席位之后，表单完全在屏幕外。现在打开或切换席位会滚入视野并聚焦首字段，输入时不重复滚动。修前 unit 和浏览器可见性回归失败，修后 10 项测试、16 个界面变体和原生点击/取消验收通过；没有修改真实额度或显示邀请码。

手机 Bot 资料页的「运行模型」「Agent」可直接点击设置。DeepSeek 是模型，Codex 是承载会话与工具的官方 CLI 运行器，二者保持解耦。开发版允许 GPT 订阅或 DeepSeek，内测版只允许 DeepSeek；当前运行器只有 Codex。模型变更仅解除不兼容会话绑定，不删除原 Agent 会话、不重置角色/技能/权限。保存取当前最新 Bot，旧模型会话的迟到创建回包不能重新绑定。

开发版私人配置加入新的首次注册凭据；构建和验证不使用该凭据注册节点，也不撤销它。正式注册只由安装后的手机完成。`files/clash/tailscale-vibelink-dev` 身份目录保持不变，只创建、不清理，不随 APK 版本或导入 profile UUID 变化；已授权身份重启时复用原状态。内测 APK 不含私人配置或该凭据；开发 APK 仅由私有开发更新源分发，凭据不入 Git。

原生内核两 ABI 重编：所有 sink 隐藏 Tailscale key，系统 logcat 也隐藏授权链接；受限 JNI 通道保留链接供应用内存缓存，界面转发前继续脱敏，未破坏交互授权。资料页与状态/日志相关 34 项定向 JVM 测试通过，Go 脱敏测试及权限/状态路径静态复核通过。

本次隔离验证：Mac 本机 HY2 → YouTube 200；Windows 经临时 UDP 桥、已有 tailnet 与现有 Mac HY2 → YouTube 200、Google 204。此前 UDP 路径瞬态失败后重测恢复；服务重启请求被系统拒绝，实际没有重启服务，不把恢复归因于重启或新 key。未更改 Windows 系统代理、Tailscale 身份、ACL 或公网监听。

边界：没有连接 ADB 手机，手机内嵌 tsnet 的首次注册及完整出网仍需安装后的设备验收。现有网络验证不能替代手机端实测。Tailscale 一次性授权 key 在首次注册后自动失效与已注册设备身份是不同概念，参见 [官方授权 key 说明](https://tailscale.com/docs/features/access-control/auth-keys)。
