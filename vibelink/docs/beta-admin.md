# 桌面内测管理

开发者在本机登录开发工作区后，从「Hub 工作区」或「设备与连接」进入「内测管理」。普通内测账号没有此入口；直接打开页面也不能获取管理数据。

- **邀请码**：现有 10 个内测席位可单独显示、复制邀请码，查看激活时间和最近设备。复制后由管理员自行交给对应用户，不代表已经发送。一个邀请码对应一个账号，多设备共享该账号的用量；不要多人共用邀请码。
- **用量**：选择日期查看 UTC+8 的每用户请求数、实际输入/输出/总 token、缓存及估算。缓存已包含在输入中，不重复相加；缺少上游 usage 时单列估算。历史日期不拿今日计数补齐。GPT 订阅用量不在 DeepSeek 网关账本中。
- **调用记录**：全局最近 200 条请求再按所选日期筛选，不是完整历史审计。只包含时间、模型、状态和计量，不包含提示词、回答或鉴权凭据。
- **额度**：编辑每日请求、每日计费 token、每日输入字节、并发数及每分钟请求数。三项每日额度填 0 表示不限；并发 1–16，每分钟至少 1。修改不会重置已消耗用量。

限额保存携带 `expectedRevision`。其他窗口已修改时返回冲突；超时、断线或回执无法核对时显示「结果未确认」。两者均必须显式刷新，核对当前值后才能继续编辑，不能自动重试。Hub 在持久化成功后才提交新额度和修订号，磁盘失败不会只改内存。

管理员凭据仅由桌面 Main 从固定本机内测目录读取，只请求 `http://127.0.0.1:18998`；不会回传 Renderer。开发者身份须已经登录、经 Hub 验证、未到期且已提交到本机原工作区。账号切换和到期会取消在途管理请求；迟到回包不能写入新账号界面。

后端接口：`GET /api/beta/tenants`、`GET /api/usage/users?day=YYYY-MM-DD`、`GET /api/usage/requests`、`POST /api/usage/limits`。普通用户只能读取自己的 `/api/usage` 或 `/api/beta/quota`。本批不提供新建、轮换或撤销邀请码，也不自动向别人发送消息。

验证：78 项 Hub 测试、12 项 Main 权限/服务测试、30 项 Renderer 定向测试、16 个浏览器界面变体及全量 TypeScript 检查通过。固定上游重放的 47 个修改文件和 86 个 overlay 文件逐字节一致。生产只读验收记录在部署证据中；没有用真实用户额度做测试写入。

2026-11-09 运行验收：桌面 Main 已从运行中的内测 Hub 读取 10 个席位、2 条用户用量行和 4 条既有调用记录。旧审计缺少 `workId` 时按无关联 Work 展示，不阻断整个记录列表。邀请码默认隐藏，未向别人发送消息，也没有修改真实用户额度。开发与公网内测 Hub 最终均更新到 0.5.0；桌面沿用原 userData 和登录身份。
